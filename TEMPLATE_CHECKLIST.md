# AI Radar template checklist

- [ ] Run `$onboard-observatory`; choose greenfield setup or approve a read-only inventory of exact existing knowledge/project locations.
- [ ] Review the proposed Observatory mapping before allowing any staged migration.
- [ ] Interview for projects, people, organizations, tools, repositories, feeds, core ideas, priorities, and explicit noise exclusions.
- [ ] Replace `config/watchlist.json` with topics and sources you actually want.
- [ ] Replace `config/projects.json` with concrete goals and discriminating keywords.
- [ ] Keep The AI Daily Brief always-on unless you intentionally change the editorial-source policy.
- [ ] Decide whether GitHub issue Share Sheet capture should be enabled.
- [ ] Keep X bookmark polling disabled unless you explicitly accept its current API cost and privacy boundary.
- [ ] Configure repository visibility before generating private reports.
- [ ] Review Actions artifact visibility for repository collaborators.
- [ ] Add a license appropriate for your distribution plan.
- [ ] Run Python tests and the dashboard build before the first push.
